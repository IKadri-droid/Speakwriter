Votre navigateur ne supporte pas la reconnaissance vocale (Web Speech API).

Ouvrez cette page avec un navigateur basé sur Chromium — Google Chrome, Microsoft Edge, Brave, Vivaldi ou Opera — pour utiliser SpeakWritter.

Firefox et Safari n'implémentent pas encore cette API du navigateur ; ce n'est pas réglable côté application.
